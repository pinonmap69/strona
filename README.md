# EtnaGlamp

Strona internetowa dla EtnaGlamp – jedynego pola namiotowego i glampingu na zboczach Etny powyżej 1500 m n.p.m.

## Uruchomienie

Otwórz plik `index.html` w przeglądarce lub uruchom lokalny serwer:

```bash
npx serve .
```

## Struktura

- `index.html` – główna strona
- `css/styles.css` – style (paleta 60-30-10)
- `js/main.js` – nawigacja mobilna i animacje
- `images/` – zdjęcia i logo
